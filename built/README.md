# built/ — development binaries and AOT work products

This temporary development repository tracks tested native launcher binaries and other generated results in this directory.

- `linux-x86_64/GodHand_Recomp_Launcher`: GTK3/SDL2 launcher, generated by GitHub Actions after tests pass. Requires GTK3, SDL2 and libarchive runtime libraries on Ubuntu.
- `reports/`: diagnostic metadata from the source-disc scan, analyzer and recompiler.
- `aot/`: generated C++ archive when the recompiler manages to produce it. This is not a playable binary.

The launcher only runs a real `GodHand_Recomp_Game` executable once one is actually built and present at `~/.local/share/HodgkinsStudios/GodHand_Recomp/bin/GodHand_Recomp_Game`. The runtime integration is not complete.

The existing game ISO remains under `iso/` in Git LFS. Never treat generated source as equivalent to a complete native game.

- `linux-x86_64/GodHand_Input_Diagnostic`: SDL2 input and screen-mode diagnostic, not gameplay. Press Esc to cycle display modes and F10 to exit.
